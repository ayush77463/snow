📖 Client Setup Instructions

                                

                                    

                                        Claude Desktop / Claude Web
                                        

                                            • Local stdio: Run snow setup --host claude to auto-configure.

                                            • Remote HTTP: Add MCP Server with URL http://127.0.0.1:8771/mcp (or your public HTTPS endpoint). OAuth 2.1 authentication initiates automatically.
                                        

                                    

                                    

                                        ChatGPT (Custom Connectors / Developer Mode)
                                        

                                            • Requires a public HTTPS endpoint (use snow expose or Docker/Caddy).

                                            • Endpoint URL: https://<your-domain>/mcp.

                                            • Auth: OAuth 2.1 Code Flow with PKCE S256.
                                        

                                    

                                    

                                        Gemini Antigravity / Cursor IDE
                                        

                                            • Gemini / Antigravity: Run snow setup --host gemini or connect to the Remote MCP endpoint.

                                            • Cursor: Run snow setup --host cursor to write configuration to .cursor/mcp.json.
